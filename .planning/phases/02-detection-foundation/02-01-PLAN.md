# Plan 02-01: Deterministic URL and Text Heuristics Engine

<objective>
Implement the core `DeterministicHeuristicsEngine` in `backend/app/detection/heuristics.py` to evaluate suspicious URL patterns, IP addresses, misleading subdomains, punycode lookalikes, structural anomalies, and urgency language, returning structured `EvidenceItem` objects.
</objective>

<tasks>
<task id="task-2.1.1">
  <title>Implement Heuristic Check Functions and Engine</title>
  <read_first>
    backend/app/schemas/scan.py
    backend/app/core/domain.py
    .planning/REQUIREMENTS.md
  </read_first>
  <action>
    Create `backend/app/detection/heuristics.py` containing:
    1. `detect_ip_hostname(url: str, hostname: str | None = None) -> EvidenceItem | None`
       - Checks if hostname is a raw IPv4 or IPv6 address using python's `ipaddress` module.
       - Returns `EvidenceItem(type="ip_hostname", source="heuristics", severity="high", explanation=...)` if true.
    2. `detect_punycode_and_lookalike(hostname: str) -> EvidenceItem | None`
       - Checks for `xn--` prefix in labels or IDN homoglyphs.
       - Returns `EvidenceItem(type="punycode_homoglyph", source="heuristics", severity="high", explanation=...)` if detected.
    3. `detect_misleading_subdomains(target_reference: str) -> list[EvidenceItem]`
       - Uses `tldextract` parts from `domain.py`.
       - Checks if subdomains contain high-profile financial/tech brand keywords (e.g., `paypal`, `apple`, `google`, `microsoft`, `chase`, `wellsfargo`, `amazon`, `netflix`, `bankofamerica`) when the registered domain is not that brand.
       - Returns `EvidenceItem(type="misleading_subdomain", source="heuristics", severity="high", explanation=...)`.
    4. `detect_url_structure_anomalies(url: str) -> list[EvidenceItem]`
       - Flags length > 100 characters (`url_excessive_length`, severity="medium").
       - Flags `@` symbol in authority/path (`at_symbol_redirect`, severity="high").
       - Flags excessive hyphens (> 2 in hostname) (`excessive_hyphens`, severity="low").
       - Flags deep subdomain nesting (>= 4 levels) (`deep_subdomain_nesting`, severity="medium").
    5. `detect_urgency_and_credential_language(text: str | None) -> list[EvidenceItem]`
       - Regex search for urgent threats ("account suspended", "verify within 24 hours", "immediate action required").
       - Regex search for sensitive credential queries ("verify password", "confirm your SSN", "enter PIN").
       - Returns `EvidenceItem(type="urgency_language"|"credential_harvesting_language", source="heuristics", severity="medium", explanation=...)`.
    6. `DeterministicHeuristicsEngine` class with methods:
       - `analyze_website(url: str, target_reference: str, page_title: str | None = None, visible_text: str | None = None) -> list[EvidenceItem]`
       - `analyze_email(sender: str | None, subject: str | None, body_text: str | None, links: list[str]) -> list[EvidenceItem]`
    7. Export `DeterministicHeuristicsEngine` from `backend/app/detection/__init__.py`.
  </action>
  <acceptance_criteria>
    - `backend/app/detection/heuristics.py` exists and defines `DeterministicHeuristicsEngine`.
    - `DeterministicHeuristicsEngine.analyze_website` returns a list of valid `EvidenceItem` objects.
    - Zero external network requests made during heuristic analysis.
  </acceptance_criteria>
</task>
