<task id="task-2.3.2">
  <title>Spike 2: Gmail DOM Extraction Prototype</title>
  <read_first>
    Phishing_Detection_App_Flow.md
    .planning/ROADMAP.md
  </read_first>
  <action>
    In `extension/spikes/gmail-extraction/`:
    1. Create `extract.js` with DOM selectors for active desktop Gmail message thread:
       - Subject extraction: selector `.hP` (max 256 chars).
       - Sender extraction: selector `.gD` (email address / domain).
       - Bounded body text extraction: selector `.a3s.aiL` (truncated to 3000 chars max).
       - Link extraction: `a[href]` elements within body (capped at 10 links).
    2. Implement boundary failure handling:
       - If selectors do not find an open email (e.g. user is in inbox list view), return explicit `{ success: false, reason: "no_open_message" }` rather than throwing errors.
    3. Document DOM resilience findings in `SPIKE_REPORT.md`.
  </action>
  <acceptance_criteria>
    - `extension/spikes/gmail-extraction/extract.js` exists and exports extraction function.
    - Gracefully handles missing DOM elements without crashing.
    - `extension/spikes/SPIKE_REPORT.md` documents findings for both spikes.
  </acceptance_criteria>
</task>
