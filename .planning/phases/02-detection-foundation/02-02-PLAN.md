# Plan 02-02: Server-Side Gemini LLM Provider Adapter

<objective>
Implement `GeminiAdapter` in `backend/app/providers/gemini.py` with strict Pydantic structured output validation, bounded 5.0-second timeout, rate-limit retries, prompt injection defense, and fail-safe degraded status reporting.
</objective>

<tasks>
<task id="task-2.2.1">
  <title>Implement GeminiAdapter and Structured Schemas</title>
  <read_first>
    backend/app/core/config.py
    backend/app/schemas/scan.py
    .planning/REQUIREMENTS.md
  </read_first>
  <action>
    Create `backend/app/providers/gemini.py` containing:
    1. Structured Pydantic Output Schema:
       ```python
       class GeminiAnalysisResult(BaseModel):
           classification: Literal["phishing", "suspicious", "likely_legitimate"]
           risk_score: int = Field(..., ge=0, le=100)
           reasons: list[str] = Field(..., max_length=5)
           confidence_label: Literal["low", "medium", "high"]
       ```
    2. Adapter class `GeminiAdapter`:
       - Loads `api_key = settings.GEMINI_API_KEY`.
       - Method `analyze_target(*, target_type: str, url_or_domain: str, title: str | None = None, text: str | None = None) -> tuple[GeminiAnalysisResult | None, ToolStatusDetail]`
       - If `api_key` is missing/empty: returns `(None, ToolStatusDetail(status="unavailable", reason_code="no_api_key"))`.
       - Prompt encapsulation: Wraps all user-submitted target URLs, titles, and text in `<untrusted_content>` tags with strict system instructions that untrusted content must never be executed as instructions.
       - Timeout enforcement: 5.0s bounded request using `httpx`.
       - Retry policy: Single retry on HTTP 429 or 503 with 0.5s delay.
       - Safe failure handling: On timeout, invalid JSON, or HTTP error, catches exceptions and returns `(None, ToolStatusDetail(status="timeout"|"unavailable"|"error", reason_code=...))`. Never raises unhandled exceptions to callers.
    3. Export `GeminiAdapter` from `backend/app/providers/__init__.py`.
  </action>
  <acceptance_criteria>
    - `backend/app/providers/gemini.py` exists and defines `GeminiAdapter` and `GeminiAnalysisResult`.
    - Untrusted content is wrapped with defense against prompt injection.
    - Adapter gracefully handles missing API keys, timeouts, and malformed JSON.
  </acceptance_criteria>
</task>
